# AURA optimizer experiments

Setup (creates `venv/` from `requirements.txt`):

```bash
./install.sh
```

Run all cases and refresh the paper figures/tables:

```bash
./run_all.sh
```

Or run a single case:

```bash
./1-non_holomorphic/run.sh
./2-holomorphic/run.sh
./3-multivariate_c4/run.sh
./4-PINN/run.sh
```
